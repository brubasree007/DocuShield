Multi-Stage Forgery Detection

Combines spatial computer vision, OCR text field extraction, metadata analysis, and neural audit.

Error Level Analysis (ELA)

Resaves documents at controlled compression ratios to amplify pixel-level edit deltas. Generates high-contrast ELA heatmaps highlighting copy-paste regions.

EXIF & PDF Metadata Audit

Inspects creator software signatures, producer engines, modification timestamps, and flags usage of editing software such as Photoshop, Canva, or GIMP.

Groq AI Logical Audit

Evaluates extracted OCR text for impossible expiry dates, ID code mismatch, font inconsistencies, and linguistic anomalies using Llama-3.3-70b.

Copy-Move Clone Detection

Uses OpenCV feature matching algorithms to detect duplicated text blocks, signature copies, or forged seal impressions.

Authenticity Score Ring

Generates a unified 0-100 authenticity score broken down into 5 sub-scores: Image Quality, Metadata, OCR, Vision Forgery, and AI Prediction.

Automated PDF Verification Reports

Export comprehensive PDF forensic audit reports complete with decision reasoning, sub-scores matrix, and legal verification evidence.
